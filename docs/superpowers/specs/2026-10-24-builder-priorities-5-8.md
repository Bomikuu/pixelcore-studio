# Builder priorities 5–8

Extend the approved dark publishing workbench natively, without agents.

5. Manage saved templates and sections: rename, descriptions/tags, archive/restore/delete, optimistic versions, immutable template versions and restore/export. Copied page content remains independent. Archive hides a design; delete frees library capacity. Keep existing JSON imports compatible, including page titles up to 180 characters.
6. Page settings: global page title, search description/title, social title/description/image, canonical HTTP(S) URL and indexing choice. Preview/review always noindex; private host pages retain stricter policy. Show heading, missing image and alt-text findings. Routes/navigation remain owned by the host.
7. Media: authenticated host-owned image upload, validated raster formats and bounded size, generated optimized renditions, approved asset selection, image aspect/fit/focal point and alt text. Display missing references with replacement tools, including imported templates. No arbitrary remote imports or duplicate production asset store. Standalone uses its own local demo media directory.
8. Premade additions: accessible FAQ, keyboard-operable tabs with readable non-JS fallback, native asset video, contact, linked map/location, opening hours, logo list and feature/service sections. All use global fonts and responsive layouts. Contact uses real links; submission forms require a host contract.

Preserve strict JS/Python validation, SSR parity, private RSVP boundary, and editor-free public entry points. Use automated tests/checks only; no builds, browser or visual checks.
