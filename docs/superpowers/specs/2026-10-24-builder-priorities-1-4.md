# Builder priorities 1–4

The user authorized implementing audit roadmap items 1–4. Preserve the current dark editor, primary/secondary font-family lock, public renderer boundaries, immutable reviews and host authorization. No builds or visual/browser checks. No Docker startup. Medframe stays adapter-ready.

1. Recovery/history: local document-only recovery, scoped by host-issued user/tenant/site key, seven-day expiry, clear after successful save and explicit discard. No resolved data or guest state. Show restore/export/discard and retain stale-version recovery for export rather than overwriting newer server work. List immutable website revisions with draft/live labels; inspect a revision and restore it as a new draft through optimistic version checks. Live publication stays unchanged.
2. Data: host-approved source/field catalog with text, URL, asset and currency fields. Bind text/image/link/alt, protect bound values, explicitly detach. Repeater is a container with one editable card template, approved source, bounded offset/limit, optional scalar equals filter and sort; render empty/error/loading states without querying arbitrary endpoints. Resolve only the supplied public-safe envelope. PixelCore supplies actual catalog/event sources; local data is labeled sample data.
3. Globals: tenant-scoped linked section with immutable versions, independent draft/published pointers, optimistic updates and explicit global publish showing affected pages. A global-section document node contains sectionId and one copied fallback section. Published pages resolve the latest published section; saved review data freezes the section version. Copies remain independent; detach produces an editable local copy. Editing linked content opens an isolated section editor; publishing it must not publish page drafts. No recursive links.
4. Responsive: fixed desktop → tablet → phone inheritance and tablet-before-phone emitted CSS. Per-property reset, per-device visibility, padding sides, grid/stack alignment/wrapping, fluid percent widths, min/max bounds. Height respects breakpoints. Responsive motion/freeform controls are explicitly desktop-only unless fully supported. Contrast derives heading size from the renderer scale. Preserve keyboard/IME behavior and normal-flow mobile defaults.

Cross-cutting: strict equivalent JS/Python schemas, no executable imports, no private guest binding sources, scoped automated regression tests, adapter declarations and user documentation.
