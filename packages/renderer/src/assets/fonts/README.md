# Font sources

Self-hosted variable fonts from the official Google Fonts repository. Each font ships with its SIL Open Font License notice.

- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope): Manrope[wght].ttf and OFL.txt.
- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond): CormorantGaramond[wght].ttf and OFL.txt.

Retrieved 2026-10-23. No paid reference font or brand asset was copied.
