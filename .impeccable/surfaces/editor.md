# Editor

Mode: Operate. Approved user reference: docs/references/editor-workspace-reference.png. Light/dark Wix-like workbench (light by default) with a slim tool rail, Pages/Layers, central website and contextual inspector. Signature interaction: choose a responsive design from a real popup preview, insert it and edit the actual page. Template/Add pickers are modal libraries. Header/footer ownership is explicit. Context is prefilled from the host; wedding RSVP uses existing invitation records and authorization. Code-first; no visual/browser checks or builds under the current policy.

Typography uses a primary heading and secondary body family, set globally in Theme & branding; individual selection cannot override families. Template popup includes Built-in/My templates, Add template and Import JSON. Import validates and previews portable JSON before saving; applying is a separate undoable action. The destination font pair and source context remain authoritative.

Priorities 1–4: Data and Shared sections rail tools; History and conditional Recover toolbar actions. History compares draft/live layout with current approved data in both previews. Recovery retains unresolved prior copies and guards late save/logout races. Shared sources edit in isolation and publish independently with affected-page confirmation. Responsive fields show inheritance and reset individually. Keep the incumbent tokens and canonical UI factory.

Priorities 5–8 extend the same Operate surface with saved-design management, Search & sharing in the page inspector, native image uploads/replacement tools, and premade FAQ/tabs/video/contact/location/hours/logo/features. Management uses one dialog with inline deletion confirmation. Page/image configuration stays in the inspector. Upload states and library errors are persistent/retryable; no additional aesthetic world or font-family overrides are introduced. Automated DOM, SSR, API and schema checks are the authorized evidence; browser visual acceptance remains unperformed.

Appearance/focus refinement: shared light/dark tokens, a persistent sun/moon rail action, restrained SVG command icons, fixed custom tooltips for sidebar/toolbar help, target reveal/focus on selection, caret/scroll preservation after inspector edits, and actual preview interaction for tabs/disclosures/safe links. Keep source-authorized RSVP submission on the live host. Native Enter on structural nodes selects without creating an editable container. Verification remains automated DOM/schema/SSR checks; no visual/browser inspection.

Modal workspace refinement: branding/media/shared/data tools now open a large shared dialog with horizontal navigation. The palette/font/color editor sits beside a read-only draft preview. Media uses approved thumbnail cards, selection details and an Add media upload card; upload is inline with retry/pending state retained across tool switches. Pages/Layers and contextual element settings remain in the canvas workbench. The page inspector links to branding instead of exposing duplicate theme fields. A media choice returns focus to the selected/inserted canvas element. Full-height dialogs on phones and bounded lazy thumbnail batches are code-verified, without browser layout claims.

Element styling refinement: common illustrated choices lead the inspector, with detailed settings behind a native Advanced styling disclosure. Two-column choice cards use website theme colors, decorative geometry and canonical named buttons; selection is explicit and custom changes clear stale selection. One undoable operation applies ordinary validated styles to the current screen, preserving bindings, global fonts and other device overrides. Use the same inspector on mobile; closed disclosures never receive hidden-field focus.

Component Lab links from standalone Studio and manages an optional approved catalog. Its branded library and preview/configuration page live outside installed packages. Installed editors expose only the optional catalog picker and declared controls; component rendering remains an inert native fallback until the host explicitly enables the optional public runtime. Host data and private operational widgets retain their existing boundaries.

Share opens Review center with creation/access/lifetime, paged links, owner discussion filters, revocation and recorded-width element navigation. Review & publish combines blockers/warnings, structural live comparison, global impact and retry. Connected data has refresh/error/last-success status. Template packs explain source/feature requirements; saved designs load content only after selection. Canvas edits patch existing nodes; short-height and coarse-pointer rules preserve reachable tools. Font availability is explicit and remains global.
