# Website Builder

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Business owners and their teams editing storefronts, event websites, and landing pages in PixelCore, Medframe, DineEase, and future applications.

## Product Purpose

One installable editor and template renderer, maintained once. The host system supplies actual approved data and permissions. Success is direct manipulation without duplicating operational records.

## Positioning

A Wix-like canvas-first editing workflow with a separate live-data binding layer. The editor and renderer install into host applications. Standalone Studio additionally owns administrator-only component import and preview; its approved catalog is an optional integration, and its management app is excluded from installed modules. No hosted service has been published by this implementation.

## Operating Context

Operate mode. Frequent desktop editing; responsive published pages. English initial UI, host locale for data. Future locales must preserve IME input.

## Capabilities and Constraints

Standalone Studio additionally owns shared login, the business website overview, profile/avatar settings and analytics setup. Verified platform connection opens the owning business workspace; documents and permissions remain in the host. Component administration is a separate capability. Tracking configuration is a draft/publication setting, verification is explicit, and public tracking requires affirmative host consent. No visitor reports or performance scores are fabricated.

Live and fixed sites; templates and elements; inline text; structured dragging; optional bounded free positioning; branding import; font and color controls; contrast; backgrounds and transitions; immutable previews with named guest comments. Checkout, clinical records, bookings and RSVP authorization remain in the host. No builds or visual inspections without explicit request. No publishing to a remote registry in this implementation.

## Brand Commitments

Wix is the user-pinned interaction reference. User-supplied editor reference: large canvas, slim tools, compact inspectors and popup Template/Add libraries. The user subsequently requested light mode, restrained button icons, custom sidebar tooltips and focus that follows element selection. Light is the default; dark remains available. Context setup pre-fills known business/event details. Use code-first implementation, existing approved sample images, and no concept tournament that substitutes for the requested editor.

## Evidence on Hand

The PixelCore audit and approved implementation plan in docs. Existing event/storefront renderers and Medframe React website code were inspected. No commercial metrics or testimonials are available.

## Product Principles

One source of rendering truth. Stable identities. Live connections never silently overwrite business records. Drafts stay separate from publication. Guest review grants no operational actions.
